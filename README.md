# 4elka

Челка MacBook как рабочая поверхность. Приложение живёт в вырезе экрана: показывает
историю буфера обмена и снимки экрана, отдаёт файлы перетаскиванием, управляет
музыкой, показывает календарь, погоду и заряд устройств.

Сделано под себя, для MacBook Pro 16″ с челкой на macOS 26. Отдаётся как есть —
если пригодится, забирайте.

## Чего оно НЕ делает — и это главное

Приложению **не нужно ни одного системного разрешения.** Ни записи экрана, ни
управления компьютером, ни геолокации, ни доступа к календарю, ни полного доступа
к диску. Это не случайность, а условие, с которого всё начиналось:

- **снимки экрана** берутся из буфера обмена, а не с экрана: `cmd+shift+ctrl+4`
  штатно кладёт снимок в буфер, приложение его оттуда и подхватывает;
- **вставка** не эмулируется — приложение кладёт выбранное в буфер, а вставляете
  вы сами, как обычно;
- **календарь** считается арифметикой, а не читается из ваших календарей;
- **погода** берётся по фиксированным координатам, без определения места;
- **музыка** читается через системный механизм «сейчас играет», а не через
  копание в чужом приложении.

Ещё оно не подменяет системные окошки громкости и яркости, не следит за фокусом,
не отправляет наружу ничего и не требует учётной записи.

## Что умеет

**История буфера.** Всё скопированное складывается в панель: текст, картинки,
файлы. Отдельные вкладки под снимки экрана и файлы, поиск по содержимому
(регистр и «ё/е» не мешают), закрепление нужного, удаление лишнего. Квоты
разумные: 200 текстов, 30 картинок, 50 файлов.

**Карточка подтверждения.** Скопировали — из челки выезжает карточка с тем, что
попало в буфер: текст строкой, картинка миниатюрой с размером, файл именем.
Живёт три секунды и уезжает.

**Перетаскивание наружу.** Выделяете `cmd`-кликом несколько снимков и тащите
мышью прямо в Finder, письмо или чат. Файлы готовятся в момент начала жеста, с
человеческими именами вида «Снимок 2026-08-21 15-48-00».

**Полка файлов.** Кинул файлы прямо на челку — они там лежат, пока не заберёшь.
Утащить мышью в другое окно или отправить по AirDrop. Полка хранит ссылки, а не
копии: исходники не дублируются, а пропавшие файлы из полки исчезают сами.

**Музыка.** Название, исполнитель, обложка, полоса позиции и кнопки. Работает с
чем угодно, что публикует «сейчас играет» — проверено на Яндекс Музыке и на
ютубе в браузере.

**Календарь, погода, заряд.** Сетка месяца с переключением месяцев, погода
без ключей и учёток, заряд наушников и айфона (айфон — когда подключён кабелем).
Предупреждения о заряде выезжают из челки, когда его слишком мало или уже хватит.

**Открыть с клавиатуры.** `⌃⌥V` из любого приложения раскрывает панель, повторное
нажатие складывает. Сочетание намеренно не ⌘⇧V: это «вставить без форматирования»
почти везде, и забирать его себе нельзя.

**Аварийный выход.** Иконка в строке меню: показать панель, настройки, автозапуск
при входе, выход. Приложение живёт без иконки в доке, и это единственный способ
его выключить — поэтому он есть.

## Что нужно, чтобы собрать

- **macOS 26** или новее. Ниже не соберётся: интерфейс построен на системном
  «жидком стекле», которое появилось в этой версии.
- **MacBook с челкой.** На экране без выреза приложение работает, но панель
  становится обычной плашкой у верхнего края — половина смысла теряется.
- **Command Line Tools для Xcode.** Полный Xcode не нужен:
  ```bash
  xcode-select --install
  ```

Зависимостей Swift ноль — ни одного внешнего пакета.

## Сборка и запуск

```bash
git clone https://github.com/adylenya/4elka.git
cd 4elka
make adapter   # собирает мостик к системному «сейчас играет», один раз
make build
make run
```

`make adapter` скачивает и собирает [mediaremote-adapter](https://github.com/ungive/mediaremote-adapter)
— чужой код под лицензией BSD-3, без него не будет только музыки. Подробности в
[THIRD-PARTY-NOTICES.md](THIRD-PARTY-NOTICES.md).

Тесты:
```bash
make test
```
Запускать их надо именно так. Голый `swift test` в этом окружении падает: в
Command Line Tools нет модуля `XCTest`, а `Testing.framework` лежит на диске, но
сборщик не знает путей до него — обвязка их подставляет.

## Необязательное

**Заряд айфона по кабелю** читается утилитой `ideviceinfo`:
```bash
brew install libimobiledevice
```
Без неё просто не будет строки про телефон — остальное работает. По блютусу и
через iCloud заряд айфона наружу не отдают, поэтому только кабель.

## Где лежат данные

```
~/Library/Application Support/4elka/
  index.json              список записей истории
  index.json.broken-*     испорченный индекс, отложенный при запуске
  blobs/                  картинки и снимки экрана
  shelf.json              полка файлов (ссылки, не копии)
  settings.json           настройки
```

Файлы создаются с правами `0600` — читать их может только владелец. Если при
запуске индекс окажется испорченным (например, приложение выключили посреди
записи), он **не стирается**: рядом появляется `index.json.broken-<время>` с
исходными байтами, а история начинается с пустой. Так у вас остаётся шанс
достать из неё что-то руками.

Всё лежит **на вашей машине и никуда не уходит**. История не шифруется — если
скопировали пароль, он окажется в этом файле. Приложение старается такое
пропускать (менеджеры паролей помечают буфер особым образом, и эта пометка
уважается), но полагаться на это не стоит.

Стереть историю можно кнопкой в настройках или руками:
```bash
rm -rf ~/Library/Application\ Support/4elka
```

## Как выключить и удалить

Выключить — «Выйти» в меню иконки в строке меню. Удалить — стереть каталог
данных выше, снять автозапуск в настройках приложения (или просто выключить его
до удаления) и удалить сам собранный файл.

## Честно о состоянии

Это личный инструмент, а не продукт. Он собран и проверен на одной конфигурации:
MacBook Pro 16″ с M1 Pro, macOS 26.5. На другом железе, на внешнем мониторе и на
маках без челки поведение панели проверено только тестами, но не глазами.

Приложение не подписано сертификатом разработчика. При первом запуске собранного
бандла macOS может спросить подтверждение — это нормально для программы, собранной
из исходников, а не купленной подписи.
