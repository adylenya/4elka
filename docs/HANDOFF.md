## Как эта сессия дошла до «весь код готов»

Контекст сжимался, и почти одновременно умерли на лимите сессии три ревьюера и два
исполнителя. Первая проверка `git worktree list` после этого показала: **за время,
пока контекст был сжат, уже было влито почти всё** — задача 30 (сборка панели),
задача 31 (главный жест), починка плеера, почти всё четвёртое ревью. Разбор состояния
шёл не по памяти разговора, а по фактам: `git log`, `git worktree list`,
`git merge-base --is-ancestor` на каждую ветку.

Из живого нашлось два невлитых куска (погода — фикс отказов и битого кэша; хоткей из
настроек — регистрация настоящего сочетания вместо вечного значения по умолчанию) и
один настоящий баг, вскрывшийся только при слиянии: **гистерезис заряда мог оказаться
не меньше зазора между порогами** — набор `low=99, high=100, hysteresis=1` проходил
проверку целиком, хотя батарея, гуляющая между 98 и 100, выдавала бы «заряд на
исходе» на каждом проходе через 98. Дописано: гистерезис жмётся первым, а если и
минимума не хватает — раздвигается сам зазор.

Дальше выяснилось, что из задачи 32 («настройки должны доходить до дела») реальный
провод уже почти весь существовал — через предыдущие слияния заряд, погода, тумблеры
карточек, хоткей и всё остальное оказались подключены. Не хватало только страховки
на будущее: теста, который через `Mirror` сверяет список полей `Settings` со списком
полей, у которых есть заявленный ответственный. Написан и доказан намеренной порчей.

## Правила, выведенные болью

**Тесты запускать только через `./scripts/test.sh`.** В Command Line Tools нет модуля
`XCTest`, а `Testing.framework` есть, но SwiftPM не знает путей до него.

**Предупреждения мерить только так:** `rm -rf .build && ./scripts/test.sh 2>&1 | grep -c "warning:"`.

**После компактификации сверяться с фактами репозитория, а не с памятью разговора.**
`git log`, `git worktree list`, `git merge-base --is-ancestor <ветка> HEAD` на каждую
ветку — это надёжнее, чем «помню, что дожидалось слияния».

**Работа умершего от лимита агента лежит в его воркри — искать, не считать
потерянной.** Дважды не хватало маленького куска, дописанного за десять минут.

**Тест, написанный по факту существующего поведения, закрепляет и дефект.** Ревью
нашло три таких за сессию. Тест должен выражать требование, а не наблюдение —
и доказывать себя намеренной порчей проверяемого условия.

**Одно и то же значение, считаемое в двух местах, — источник дефектов.** Гистерезис
против зазора между порогами — тот же класс ошибки, что раскладка панели против
размера окна: правило проверялось по частям (гистерезис в своих границах, пороги в
своих) и никто не сверял их вместе.

**Кто создаёт возможность — тот её и подключает.** Правило родилось на плеере и
календаре, подтвердилось на хоткее: связь между двумя работающими по отдельности
частями — самое незаметное место для дефекта, и ловит его только ревью, читающее
приложение целиком, а не подсистему.

**Снимок экрана не показывает физическую челку.** «Стык незаметен» проверяется
только человеком.

**Не запускать много агентов «на всякий случай»:** лимит сессии общий.
